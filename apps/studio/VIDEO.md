# Video skills

The original conversational orb remains the interface. Say **open a recording**, touch the orb again to choose the file, then describe the video. For example: “Make a one-minute video from my recording with screenshots of public pages about the topic. Keep my voice and add short captions.” Say **preview the timeline** for an Etro preview and **export video** for the finished MP4.

The host registers two specialist harnesses: offline `video` and opt-in `video_sources`. Six trusted recipes are retrieved individually: montage, narration, screenshots, online video, captions and revisions. Actual tools list media, read timed recording transcripts, inspect/create timelines, append/replace/remove/reorder clips, set a narration/music track, render and verify. All specialists reuse the same local Qwen weights; neither FFmpeg commands nor shell code are generated by the model.

## Local dependencies

Install FFmpeg and FFprobe on PATH, or set `FFMPEG_EXE` and `FFPROBE_EXE`. Online YouTube importing also needs yt-dlp (`YT_DLP_EXE`). Public page screenshots need Node.js (`NODE_EXE`) and Chrome/Edge, or `STUDIO_BROWSER_EXE`. The app uses Bun for orchestration, storage and FFmpeg; the isolated browser adapter runs under Node because Playwright transport was not reliable under Bun 1.3 on Windows. No additional browser binary is downloaded automatically.

Attached audio-only recordings are transcribed by the existing offline Whisper tiny English worker, in 30-second chunks with segment timestamps. Automatic transcription currently supports ten minutes. Transcripts are paginated evidence outside the Qwen prompt. This is segment timing, not word-perfect alignment or visual understanding. First-time speech-model downloads must finish before offline use.

## Edits and limits

FFmpeg trims and concatenates video/image clips, changes speed (0.5–2), fits or crops frames, adds clip captions and fades, and mixes/replaces audio. Narration does not loop unless explicitly configured. Exports use H.264/AAC MP4, at most 12 clips, ten minutes, 1920 pixels per side, 60 FPS and 150 MB. Uploaded media can be up to two hours and 150 MB. Each timeline save retains a revision and each render creates a new media item; originals are preserved. Source credits and the timeline are retained beside the export as `credits.json`.

Etro supplies video, image, text and audio layers for requested timeline previews. Browser codec support and Etro playback can differ from FFmpeg; the verified MP4 is authoritative. Preview volume is capped at 1 while FFmpeg gain supports 2. Browser audio playback is initiated by the preview's Play button.

The public website does not run native FFmpeg, download sources or control the visitor's computer. These capabilities require the local app. Web/news search requires `BRAVE_SEARCH_KEY`. Direct public HTTPS media links and single public YouTube links are supported; downloads may fail on source restrictions. Authenticated downloads and DRM bypass are not implemented.

Screenshot capture uses an isolated headless browser with no user cookies, JavaScript disabled, bounded public HTTPS requests and pinned public DNS. It captures the actual page, retains its URL/title and makes the PNG available as a clip. It does not control the desktop, logged-in apps, arbitrary websites requiring JavaScript, or inspect images with a vision model. Those require additional adapters. Network specialists cannot receive private saved details or private specialist handoffs.

## Verification

`bun run test` checks real FFmpeg edits, source preservation, narration, captions, still images, invalid input/ranges, cancellation and specialist handoffs. `bun scripts/probe-video.ts` separately downloads an actual FFmpeg sample, captures the FFmpeg homepage, renders a three-second MP4 and decodes it completely. Its audio is synthetic; it does not measure speech recognition or Qwen interpretation accuracy. `bun scripts/probe-video-preview.ts` serves the actual Etro React component for browser playback checks, without adding controls to the production orb.

Full narrated-video interpretation by Qwen3-0.6B still needs accuracy evaluation. The host verifies execution, dimensions, duration and decode success; that cannot establish that every creative instruction was understood correctly.
