## Source-backed design

The existing Software queue, immutable child workspaces, activity history, browser contracts and artifact hash gates are reused. Model strings remain typed data; the trusted host compiler owns syntax. This is a bounded persistent text-collection recipe, not proof of arbitrary code generation. The current source does not support an ordinary launch button; do not fabricate one or a public preview URL.

Primary sources reviewed and archived locally with retrieval/hash receipts:

- [React useState](https://react.dev/reference/react/useState) and [useEffect](https://react.dev/reference/react/useEffect): pure initializers/updaters; identical server/initial-client render; client storage read before enabling edits; writes in explicit events.
- [WHATWG Web Storage](https://html.spec.whatwg.org/multipage/webstorage.html): origin scope, storage failures and lack of a promised locking mechanism.
- [Playwright locators](https://playwright.dev/docs/locators): role/label-based checks and item-scoped Remove actions.
- [Next standalone output](https://nextjs.org/docs/app/api-reference/config/next-config-js/output) and [Bun tests](https://bun.sh/docs/test/writing-tests): actual build/start assets and awaited bounded checks.
- [W3C target size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html), [visible focus](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html), [status messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html), [reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html), and [HTML output](https://html.spec.whatwg.org/multipage/form-elements.html#the-output-element): comfortable controls, explicit labels, keyboard focus, feedback and contained layout. Captures/tests establish only the tested usability scope, not a general accessibility certification.

No new provider, secret, model download, public deployment or main promotion is required. Native voice, physical handset keyboards, account sync and broad model accuracy remain unverified.
